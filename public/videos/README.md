# Morrow idle-screen videos

Add MP4 videos here as `intro-1.mp4`, `intro-2.mp4`, `intro-3.mp4`, and `intro-4.mp4`.

For best kiosk performance, use H.264 MP4 at 1920 x 1080, 6–15 seconds long, and preferably under 10–20 MB per file. Landscape video is preferred. Videos should be muted or contain no audio.
